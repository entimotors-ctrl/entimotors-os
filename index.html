Instala ENTIMOTORS OS

Este sistema solo funciona instalado como aplicación en este dispositivo — no se puede usar dentro de una pestaña normal del navegador.

Si el botón no hace nada, tu navegador ya lo permite instalar manualmente:
  1. Toca el menú ⋮ (Chrome) o el ícono de instalar en la barra de direcciones.
  2. Elige "Instalar aplicación" o "Agregar a pantalla de inicio".
  3. Abre ENTIMOTORS OS desde su propio ícono, no desde el navegador.

Ajustes

Todo el sistema vive en este dispositivo — respalda seguido para no perder tu información.

Respaldar datos

Descarga un archivo con todo lo guardado (clientes, órdenes, inventario, ventas, caja, contenido de la web). Guárdalo en un lugar seguro — en tu correo, en la nube, donde prefieras.

Restaurar desde un respaldo

Esto reemplaza TODO lo que hay ahora mismo en este dispositivo por lo que traiga el archivo. Úsalo si cambiaste de celular o si necesitas recuperar información.

Empezar de cero

Borra TODA la información de este dispositivo (clientes, órdenes, ventas, caja, todo) y vuelve a preguntar cómo arrancar. No se puede deshacer.
